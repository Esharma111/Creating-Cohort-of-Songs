📌 Project Overview

This project focuses on analyzing a Spotify dataset to create cohorts of songs based on their features using clustering techniques. The goal is to group similar songs together.

🔍 Key Steps Performed

1️⃣ Data Collection & Preprocessing

✅ Handled missing values and duplicates to ensure data quality.

✅ Standardized numerical features for better clustering.

✅ Outlier Treatment 


2️⃣ Exploratory Data Analysis (EDA)

✅ Visualized key song attributes (e.g., tempo, loudness, energy) using Seaborn & Matplotlib.

✅ Used boxplots & histograms to identify outliers and distribution trends.

✅ Applied Winsorization to cap extreme values and reduce their influence.


3️⃣ Feature Engineering

✅ Applied dimensionality reduction (PCA) for better cluster separation.


4️⃣ Clustering & Cohort Formation

✅ Applied K-Means clustering and determined optimal clusters using Elbow Method & Silhouette Score.

✅ Compared with Hierarchical Clustering to analyze grouping effectiveness.

✅ Visualized clusters using scatter plots.


🚀 Technologies Used

Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn, SciPy)

Machine Learning (K-Means, Hierarchical Clustering, PCA)
Data Processing (Feature Scaling, Outlier Detection, Winsorization, EDA)
